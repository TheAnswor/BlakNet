     1→# BlakNet — Build Worklog
     2→
     3→## Project Overview
     4→BlakNet is a modern South African business ecosystem for Black-owned businesses.
     5→Tagline: **Built for Black Business. Built for Opportunity.**
     6→Journey: Get Exposed → Get Connected → Get Ready.
     7→
     8→## Architecture Decisions
     9→- **Framework**: Next.js 16 App Router (only `/` route is user-visible per sandbox rules).
    10→- **Routing**: Single-page app at `/` with a custom **hash-based client-side router** so users can navigate Home / Directory / Business Profile / Newsfeed / Events / Resources / Pricing / About / Login / Register / Dashboard / Admin — all without extra Next.js page files.
    11→- **Database**: Prisma + SQLite (the environment provides Prisma, NOT Supabase). The spec's Supabase schema is adapted to Prisma models.
    12→- **Auth**: Lightweight session-based auth (HTTP-only cookie + bcrypt-style password hashing via Node crypto). Real users table in Prisma. Demo login available.
    13→- **Data fetching**: TanStack Query for server state, Zustand for client state (current view, auth user, route params).
    14→- **Backend**: API routes under `src/app/api/*` (no server actions).
